# GIRIDHARRAJA T - Personal Portfolio

A modern, interactive personal portfolio website built with HTML, CSS, and JavaScript.

## Live Demo
Deploy via GitHub Pages: Settings -> Pages -> Source: main branch

## Features
- Dark / Light theme toggle
- Animated particle canvas background
- Typewriter hero text animation
- Skills section with animated progress bars
- Projects showcase with modal detail views
- Fully responsive design
- Contact section

## Tech Stack
HTML5 . CSS3 . Vanilla JavaScript
